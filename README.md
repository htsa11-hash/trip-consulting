# trip-consulting

国内旅行を、ムダなく必要最小限の費用で組むための旅程プランナーです。1ファイルのHTMLで動き、サーバーもAPIキーも使いません。

## 使い方

1. 左の欄に出発地・日程・人数・行きたい場所・希望を入れる
2. 「AIに頼む文章をコピー」を押し、ChatGPTやClaudeなど好きなAIに貼り付ける
3. AIの返答を「AIの返答を貼り付け」に貼り、「旅程を読み込む」を押す
4. 「確認すること」と「予約する順番」を見て、上から予約する
5. 実際の料金を調べたら金額欄に入力する（推定 → 確定に変わり、総額に反映）

旅程は自分のブラウザにだけ保存されます。チームで共有するときは「今の旅程をコピー」で文章を渡し、受け取った人は同じ欄に貼って読み込みます。

## ページが自動で判定すること

- 総額と1人あたりの金額（確定分と推定分を分けて表示）
- 成立しない乗り継ぎ時刻
- 車を使わない日のレンタカーと、あと数時間短くすれば1日分浮くレンタカー
- 最終日の近くにある離島・フェリーの日
- 予約する順番：飛行機 → フェリー → 宿 → レンタカー → 新幹線・バス

金額と時刻はAIの推定です。予約前に必ず各社のサイトで確かめてください。
